# 0004 Questions between agents are information requests only

- **Status:** accepted
- **Date:** 2026-11-14

## Context

Artemis (spielt planets.nu als „lomize") stellt Fragen, Urania und Aletheia beantworten sie
über das gemeinsame Logbuch „Logbuch Aletheia & Urania". Ohne klare Grenze könnten Fragen
als Aufträge verstanden werden (Daten ändern, Dinge auslösen, posten).

## Decision

Fragen zwischen Agentinnen sind reine Informationsanfragen. Artemis schreibt höchstens
3 Fragen pro Runde und nur in den Abschnitt „Fragen von Lomize". Urania und Aletheia antworten
mit Informationen und handeln nie aufgrund einer Frage. Aufträge kommen nur von Frank
(Abschnitt „Anweisungen" im Logbuch, Prompts).

## Consequences

- Keine Agentin kann eine andere zu Aktionen bringen; der Tageszyklus bleibt vorhersehbar:
  Fragerunde 08:30/18:30 → Antworten 09:00/09:30 bzw. 19:00 → Spielrunde 11:30/19:30.
- Was Artemis braucht, aber nur durch eine Aktion entsteht (z. B. neue Analyse), muss Frank anstoßen.

## Rejected alternatives

- Fragen als Aufträge zulassen: Risiko unkontrollierter Aktionen und Kosten, schwer nachvollziehbar.
